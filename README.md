# budget_fr

Atlas historique et critique des finances publiques françaises.

> **Statut : prototype de recherche.** Les chiffres et leurs limites doivent toujours être rattachés à une source explicite. L'objectif initial est 1980–2025 ; les premières séries disponibles ne couvrent pas nécessairement toute cette période.

Le développement est suivi sur une branche dédiée. Voir sa documentation avant toute interprétation des données.

Ce dépôt est public. Le code et les données tierces peuvent relever de licences différentes ; aucune redistribution de données restreintes n'est autorisée.
